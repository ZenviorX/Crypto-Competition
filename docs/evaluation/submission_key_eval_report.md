## 四、结论

OAuth 只能证明调用方持有某类工具的粗粒度权限，不能理解参数内容、提示注入、敏感数据外发和任务偏离。

关键词过滤能够识别显式特征，但无法稳定区分自动放行、人工确认和直接拒绝。

通过关闭语义检测、移除任务合约，以及同时关闭二者，可以量化不同防护层对最终结果的独立贡献。

完整 AgentGuard 使用唯一决策标准，避免多个可接受答案人为抬高准确率。
